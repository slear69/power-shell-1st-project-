## Included tools

- **what it dose** Installs and configures common development tools, VS Code extensions, VS Code settings, Windows Terminal settings, and Git options.
## code :

Manual mode: Prompts for VS Code and Windows Terminal preferences.
Automatic mode: Applies preset settings.
Installs missing tools such as Git, Python, Node.js, Visual Studio, VS Code, and Spotify using winget.
Checks and installs selected VS Code extensions.
Configures Git with a username and email.
Updates Windows Terminal font settings.
Updates VS Code for theme, font size, autosave, breadcrumbs, linked editing, and delete confirmations.
Creates missing VS Code settings and backs up the Windows Terminal settings file.
The programming setup also requires the `code` command to install VS Code extensions. It asks for confirmation before individual actions in Manual mode.
